# LitePlan 🧱✨

> **The Fast, Offline-Ready Minecraft Material Planner & Crafting Calculator for Litematica.**

[![CI Quality Gate](https://github.com/aaronrojas32/LitePlan/actions/workflows/ci.yml/badge.svg)](https://github.com/aaronrojas32/LitePlan/actions/workflows/ci.yml)
[![Deploy to GitHub Pages](https://github.com/aaronrojas32/LitePlan/actions/workflows/deploy.yml/badge.svg)](https://github.com/aaronrojas32/LitePlan/actions/workflows/deploy.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**LitePlan** is an open-source web application designed for Minecraft builders and technical players who use **Litematica**. It transforms raw schematic material exports into structured, actionable gathering plans, storage layouts, and crafting trees.

---

## ✨ Features

- 📥 **Universal Litematica Importer**: Drag and drop `.csv`, `.tsv`, or ASCII table `.txt` material exports generated by the Litematica mod.
- 📐 **Single Source of Truth Calculations**:
  - Exact total required items/blocks.
  - Stacks and remainder breakdown (e.g. `18 stacks + 32`).
  - Storage allocation: Shulker boxes (`27 slots`), single chests (`27 slots`), and double chests (`54 slots`).
- 🌲 **Recursive Crafting & Raw Material Tree**:
  - Automatically resolves crafting recipes (e.g. `Dark Prismarine` $\rightarrow$ `Prismarine Shards` + `Black Dye` $\rightarrow$ `Ink Sac`).
  - Integer craft counts with excess surplus tracking (`+3 extra`).
  - Raw resource farming summary (base mineable/farmable resources).
- 📋 **Dual-Mode Interactive Checklist**:
  - **Build Objects Mode**: Progress steppers that update project completion percentage in real time.
  - **Raw Resources Mode**: Track gathering without affecting the final placement progress bar.
- 📦 **100% Offline & Local**:
  - Persistent IndexedDB storage with automatic schema migration.
  - Full JSON backup export and import.
  - Export custom material gathering lists to `.csv` or `.txt`.
- 🎨 **Light Mode UI & Minecraft Textures**:
  - High contrast, clutter-free user interface.
  - High-resolution textures for Minecraft 1.21+ blocks and items.

## 🚀 Quick Start

### Online Web App
Access the live deployment on GitHub Pages:
👉 **[LitePlan Web Application](https://aaronrojas32.github.io/LitePlan/)**

### Local Development

```bash
# 1. Clone repository
git clone https://github.com/aaronrojas32/LitePlan.git
cd LitePlan

# 2. Checkout development branch
git checkout dev

# 3. Install dependencies
npm install

# 4. Start Vite dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🧪 Testing & Validation

LitePlan comes with a comprehensive Vitest test suite covering calculation integrity, file parsing, and project state transitions:

```bash
# Run all unit tests
npm run test:run

# Run TypeScript typecheck
npm run typecheck

# Build for production
npm run build
```

## 🌿 Git & Deployment Workflow

| Branch | Purpose | GitHub Actions |
| :--- | :--- | :--- |
| **`dev`** | Active development, features, and bug fixes | Runs CI test & typecheck quality gate (`ci.yml`) |
| **`releases`** | Stable release builds | Automatically builds and deploys to GitHub Pages (`deploy.yml`) |

> ⚠️ **Note**: Commits to `dev` do **not** deploy to GitHub Pages. Only merged releases on the `releases` branch trigger production deployment.
